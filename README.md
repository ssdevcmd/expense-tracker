# 💸 Vanilla JavaScript Expense Tracker

A clean, responsive, and intuitive web application built using HTML5, CSS3, and Vanilla JavaScript to track income, expenses, and overall account balance in real-time.

🔗 **Live Demo:** [View Expense Tracker Live](https://melodious-tapioca-47a1ce.netlify.app/)

---

## ✨ Features

- **Real-Time Balance Calculation:** Automatically computes total balance, income, and expense totals dynamically as transactions are added.
- **Transaction History:** Displays a clear historical list of all recorded income and expense entries.
- **Visual Indicators:** Uses color-coded borders (green for income, red for expense) to easily distinguish transaction types.
- **Dynamic DOM Manipulation:** Instant updates without requiring page reloads.
- **Clean UI Layout:** Designed with a modern, centered card layout for optimal mobile and desktop responsiveness.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic structural markup for the tracker container, summary cards, and transaction form.
- **CSS3:** Modern styling, Flexbox layouts, and custom card interfaces.
- **JavaScript (ES6+):** DOM event listeners, array methods (`reduce`, `map`), and dynamic element injection.
